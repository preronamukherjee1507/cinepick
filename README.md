# CinePick 🎬

**CinePick** is a lightweight, interactive web application designed to help movie lovers discover what to watch next without endless scrolling. Simply pick a genre, hit generate, and get instant film recommendations!

---

## ✨ Features

- **Genre Selection:** Filter recommendations by your favorite genres.
- **Instant Recommendations:** Quick film suggestions powered by movie data.
- **Clean UI:** Simple, dark-mode design optimized for movie night.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Data Source:** [TMDB API](https://www.themoviedb.org/documentation/api) / Custom Dataset
- **Hosting:** GitHub Pages
